- **Ask PULSE without an AI service.** GitHub Pages is static and the site must work offline, so requests are understood by a rule-based bilingual parser (column aliases, value words and intent keywords) instead of a hosted language model. It is deterministic and unit-tested, and every answer is computed by the same stats engine that is checked against R.
- **Pages from the gh-pages branch.** Enabling Pages "from GitHub Actions" needs an admin setting a tool cannot change, so the workflow builds and pushes `dist/` to `gh-pages`, which Pages serves automatically.
